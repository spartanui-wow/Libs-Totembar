# Libs - Totembar

A small bar for the things you put on the ground: shaman totems, hunter traps, monk statues and
druid Efflorescence. One click places them, and each button shows how long what you placed has left.

Works on Retail, WoW Forever and every Classic version.

## What it shows

| Class | Retail | Classic |
|---|---|---|
| Shaman | Totems in three groups: Control, Healing, Offense | One button per element (Earth, Fire, Water, Air) plus Totemic Call |
| Hunter | Traps, Binding Shot, Flare | Traps, Flare, Trap Launcher |
| Monk | Statues | Statues (Mists) |
| Druid | Efflorescence | - |

Only spells you have learned appear. New ones show up as you learn them, and Classic always casts
the highest rank you know.

## Using it

- **Click** a button to cast it. Bind keys under Key Bindings > AddOns > Libs - Totembar.
- **Point at a group button** (the ones with a small arrow) to open the rest of that group. Picking
  a spell casts it and keeps it on the bar. This works in combat.
- **Right-click** a Classic element button to remove the totem you placed.
- A **colored border** and a **countdown** show on a spell while it is placed. The thin strip under
  each group empties as the placed totem runs out.
- On Classic, a hunter trap's timer stops as soon as the trap springs.

## Settings

Type `/totembar` (or `/ltb`) to open the settings. Other commands:

- `/totembar unlock` - drag the bar somewhere else, right-click it to lock it again
- `/totembar lock`
- `/totembar reset` - put the bar back in its starting spot

You can change the size, spacing, row or column layout, which way groups open, what text shows,
whether the bar only shows in combat, and hide any spell you do not use.
